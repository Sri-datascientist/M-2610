info:
  title: Verify OTP
  description: >-
    Verifies the OTP a user entered against the one generated by SendOTP for the same mobile number. Call it when the
    user submits the code; proceed with login or the transaction only when the response is `type: success`.


    Note that a wrong, expired or never-issued OTP still returns HTTP 200 with `type: error` and a message, so check
    `type` rather than the HTTP status. Messages include "OTP verified success", "OTP expired", "OTP not match" and
    "Mobile no. empty or not numeric". A missing or invalid authkey returns 401 with "Invalid authkey".
